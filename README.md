## 🌟 О программе

**File Sorter Pro** — это компактный и мощный инструмент, разработанный для решения вечной проблемы замусоренных папок («Загрузки», «Рабочий стол»). Программа за секунды анализирует содержимое папки и аккуратно раскладывает файлы по соответствующим категориям.

---

## 🔥 Ключевые возможности

* 🚀 **Автоматическая сортировка:** Быстро распределяет картинки, документы, видео, музыку, архивы и программы по папкам.
* 📅 **Сортировка по датам:** Опция раскладки файлов по подпапкам `Год / Месяц`.
* 🖱️ **Drag-and-Drop:** Перетаскивайте любую папку прямо в окно программы мышкой!
* ↩️ **Функция отмены (Undo):** Мгновенный возврат всех файлов на свои места в один клик.
* 🛡️ **Защита от дубликатов:** Умное переименование файлов без перезаписи.
* 🎨 **iOS & Glassmorphism Design:** Стильный тёмный интерфейс с плавной сменой тем.
